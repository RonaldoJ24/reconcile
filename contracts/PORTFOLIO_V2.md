# Portfolio continuation contract v2

Frozen before new implementation/evaluation on 2026-09-16. Extends
`QUALITY_DEMO_V1.md`; v1 reports, sealed files and model artifact remain immutable.
No provider execution, final benchmark, deployment or model promotion authorized.

## Runtime

Versioned public cases use synthetic input bytes, ordinary parser/import/commit/
jobs/proposal services and session-owned state. Repeated load resumes existing
data without resetting balances. Case identifiers do not encode answers in React.
Scenarios: explicit reference, message-supported credit bundle with amount decoy,
semantic exclusion/correction, insufficient evidence, bounded adversarial evidence.
Variants are input versions; changing evidence invalidates prior decisions/cache/
recordings. Applied history is retained and requires explicit reversal.

Persist structured stage observations on existing revision/audit records. Only
executed stages get completed status; absent timing/usage/cost is null/unknown.
Record input fingerprint, source hashes/versions, rules identity, candidate context,
outputs and validators. No hidden reasoning. Human review and transaction are
separate from recommendations. Trace and comparison must refer to one immutable
input snapshot; shadow ranking never changes financial authority.

Canonical API v1 money is `amount: integer centavos`; edits are `amount_mxn: string`.
Capabilities are server-derived and state-aware. New routes/fields are additive.
Keep source ownership, CSRF, quotas, revision checks and transaction invariants.
Do not narrow financial locks without decisive PostgreSQL concurrency tests.

Recorded provider artifacts must match scenario/version, exact source content and
versions, candidate/input fingerprint, model, prompt, schema, parser, rules identity
and mode. Verify digest and run existing validators again. Test artifacts are
explicitly test-only and never loaded as authentic recordings. Unknown usage/cost
remains unknown. Runtime exposes Live / Validated cache / Recorded validated run /
Unavailable. No eligible artifact means Unavailable, without a fabricated result.

## Fresh evaluation v2 protocol

Hypothesis: semantic interpretation may resolve evidence-supported exceptions beyond
a credible deterministic baseline without increasing unsupported recommendations.
No result is required to favor a model. Financial validity and citation location
validity are distinct from independent semantic support labels.

Group all variants, paraphrases and shared entity histories by immutable `group_id`.
Assign groups using SHA-256 of `reconcile-eval-v2:<group_id>` modulo 10: 0–5
development, 6–7 validation/selection, 8–9 reserved final. Reject mixed splits or
duplicate case IDs. Manifests bind input/target hashes and protocol identity. Public
demo and reviewer-packet cases are development/exposed data, never sealed evidence.
Final execution requires an explicit guard and one-time access record after a
frozen manifest; generating a harness does not authorize final-label access.

Baselines: frozen historical v1 aggregates for context only; active conservative
rules; bounded correction/negation baseline (same engine when it can solve the
case); existing unmodified shadow ranker; Direct/Hybrid only with authentic exact
input outputs. Identical input/candidates/evidence/validators for paired comparisons.
Missing methods are unavailable, not inferred wins or safe deferrals.

No retraining/calibration/promotion here. Optional ranker operating points are raw
score thresholds 0, .25, .5, .75, .9, 1, selected on validation only by maximum
coverage with zero observed unsupported proposals (ties choose higher threshold).
If none qualifies, defer all. This is a development selection rule, not a guarantee
of real-world risk. Freeze selection before any later final evaluation.

Metrics expose raw counts and denominators: supported/unsupported proposals,
answerable resolution, precision among proposals, all-case coverage, correct and
unnecessary deferrals, provider failures/unavailable separately, citation location
validity and semantic support separately, risk versus coverage. Missing labels or
results fail validation; unknown semantic support is not a pass. Time actual method
execution including feature work; name excluded I/O explicitly. Provider attempts,
usage and cost are measured or unknown. Timeouts remain in all-case denominators.

Independent domain review uses unlabeled evidence/candidates plus response forms
and insufficient-information choice. Expected labels stay outside the reviewer
packet and runtime. Feedback requires documented adjudication; no automatic label
replacement and no claims of review until a real reviewer completes it.
